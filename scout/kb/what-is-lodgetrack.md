# What LodgeTrack does

LodgeTrack is a property management platform built for small hotels, guest houses,
B&Bs and vacation-rental hosts:

- **Calendar + channel management**: synced property calendars (Airbnb, VRBO, direct bookings via iCal) so double-bookings stop happening.
- **Unified guest communication**: every guest message in one inbox, with message templates for common questions (check-in, lost keys, parking...).
- **Team + task management**: schedule cleaners, assign tasks per booking, keep turnover moving.
- **Pricing & reporting**: occupancy and revenue per room/apartment so a host stays in control of the numbers.
- **Direct booking module**: hosts build their own website and avoid the 15–20% OTA commission.
- **AI agent**: automates the boring, repetitive guest-messaging parts.

Everything is web-based, mobile-friendly, works on slow connections.
Free tier to try; paid plans for teams. Site: https://www.lodgetrack.com — I'm the founder, reachable personally.
